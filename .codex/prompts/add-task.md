Help me add a task to the Formigio WIP system, triaging it to the right place.

## Steps to Follow:

1. **Capture the Task**: Understand what I want to add; clarify if the description is unclear.

2. **Ask Timing** (skip if I already stated it): **"When does this need to happen?"**
   - **Today** → add to today's daily file
   - **Specific future date** → add to that day's daily file (create it if it doesn't exist, with that day's recurring tasks)
   - **No specific date / when I have time** → add to `backlog.md`

3. **If Today**: Ask **"How long do you think this will take?"** for realistic planning.

4. **Route to the Correct Location:**
   - **Today**: add using the daily log format (Remaining Estimate / Focus-Notes / Challenges-Learnings), or as a simple `[ ]` item under Tasks
   - **Future date**: add to that day's file with a note on why it's scheduled then
   - **Backlog**: add under the appropriate category — Decisions Needed, Team Communication, Technical Debt, Project-Specific, or Low Priority / Someday

5. **Confirm**: Tell me where the task landed and any relevant context.
