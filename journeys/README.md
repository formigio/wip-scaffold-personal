# Journeys

This directory contains **Journey** files - a format for tracking multi-step initiatives that involve learning, planning, and iterative progress.

## When to Use Journeys

Use the Journey format when:
- The path to completion isn't fully clear upfront
- Learning and research are part of the process
- The work spans multiple sessions or days
- You need help getting "unstuck"
- Physical execution is involved (home projects, purchases, installations)

## Journey vs Project

| Aspect | Journey | Project |
|--------|---------|---------|
| **Timeline** | Has a clear end state | Ongoing or recurring |
| **Certainty** | Path involves exploration and learning | Path is relatively clear |
| **Integration** | Self-contained markdown file | Tracked in projects/index.md with review cadence |

Use Journeys for things with a clear "done" state. Use Projects for ongoing work or when you need integration with the WIP daily review system.

## Creating a New Journey

Copy `_template.md` to a new file named `YYYY-MM-DD-short-name.md` in this directory. See CLAUDE.md for the full template and guidance.

## Journey Lifecycle

1. **Inception** - Capture the desired outcome and why it matters
2. **Exploration** - Research, learn, gather information
3. **Planning** - Define goal posts, identify blockers
4. **Execution** - Work through goal posts, journal progress
5. **Completion** - Celebrate, capture learnings, archive

## Getting Unstuck

The "Next Step" section is the anti-stuck device. When uncertain, this should be the smallest possible action that creates clarity - even just "Think about X for 10 minutes" or "Ask [person] about Y".
